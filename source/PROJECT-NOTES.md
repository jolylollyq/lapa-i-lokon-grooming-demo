# Лапа и Локон · локальный макет груминг-студии

## Статус

Локальный React + TypeScript + Tailwind сайт в отдельной папке. Визуальная основа — ранее выбранный `../mockups/03-gorod.html`: ледяной фон, тёмно-синий текст, синие и лаймовые акценты, многослойная композиция первого экрана, бегущая полоса, галерея, цены, карта-иллюстрация и адаптивная навигация.

Сайт публикуется по поручению пользователя в отдельном репозитории на GitHub Pages: `https://jolylollyq.github.io/lapa-i-lokon-grooming-demo/`. Город Нижний Новгород указан по просьбе пользователя. Название «Лапа и Локон», улица и номер дома, район, электронная почта, расписание, услуги и цены вымышлены и не относятся к реальному бизнесу. В HTML стоит `noindex, nofollow`.

## Изображения и поведение

- Все фотографии — локальные изображения, созданные для проекта; фотографии реального салона не использовались.
- Галерея открывает фото в диалоге. Четвёртое, широкое фото заменено на изображение расчёсывания спаниеля (`neutral-grooming-09.jpg`).
- Форма только на странице показывает подтверждение заявки и детали ухода; реальные заявки не поступают. Код `+7` закреплён в поле телефона, десять цифр форматируются по мере ввода; проверка номера выполняется при отправке формы. Имя и телефон не читаются обработчиком, не отправляются и не сохраняются; после отправки поля очищаются. Сетевой обработчик, база данных, хранилище, почта и телефон не подключены.
- Адресная схема нарисована стилями и не является картой. Внешняя карта, построение маршрута и контактные каналы не подключены.
- Сохранены анимации: прогресс прокрутки, компактирование навигации, появление блоков, мягкое движение первого экрана, бегущая строка, эффекты карточек и галерея. При `prefers-reduced-motion` анимации отключаются.

## Запуск

В PowerShell из этой папки: `./start-demo.ps1`.

## Перед возможным реальным запуском

Заменить всю вымышленную информацию подтверждёнными данными владельца. Для реальной формы согласовать канал получения заявки, обработку персональных данных, нужные тексты и согласия. Подключать карту и маршрут только после подтверждения адреса. Для боевого запуска заменить вымышленные данные реальными и подключить согласованный канал приёма заявок.
