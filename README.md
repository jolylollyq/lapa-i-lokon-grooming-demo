# Лапа и Локон

Сайт груминг-студии: [открыть опубликованную страницу](https://jolylollyq.github.io/lapa-i-lokon-grooming-demo/).

Название студии, адрес, электронная почта, часы работы, услуги и цены в этой версии вымышлены. Нижний Новгород — реальный город; точка на схеме и адрес не подтверждают фактическое место работы салона. Фотографии созданы для макета. Фотографии из прежней версии сайта не используются на странице.

## Форма и контакты

Форма показывает подтверждение на самой странице, но не отправляет и не сохраняет имя или телефон. Контактный адрес `hello@lapalokon.example` зарезервирован как пример и не принимает письма. Схема нарисована для страницы; внешняя карта и маршрут не подключены.

## Исходники и публикация

Актуальный React + TypeScript исходник расположен в [`source/`](source/). Чтобы пересобрать корневую статическую версию GitHub Pages, установите зависимости в `source/`, затем запустите из корня репозитория:

```powershell
cd source
npm ci
cd ..
./publish-from-source.ps1
```

В `index.html` установлен `noindex, nofollow`, чтобы поисковики не индексировали концепт.
